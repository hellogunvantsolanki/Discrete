# Hasse Diagram & POSET Analyzer

A Python tool for Discrete Mathematics (Sets and Relations). It analyzes a Partially Ordered Set (POSET) and draws its Hasse diagram.

## Features
1. Checks whether a relation is a POSET (reflexive, antisymmetric, transitive)
2. Finds covering pairs and draws the Hasse diagram
3. Finds maximal and minimal elements
4. Finds the greatest and least element
5. Finds upper bounds, lower bounds, LUB and GLB of any subset

## How to run
```
pip install -r requirements.txt
python hasse.py
```
